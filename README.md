# E-Commerce Database Design (SQL Server)

A relational database for an online store, normalized to 3NF.

## Tables
categories, customers, products, orders, order_items, payments

## What's included
- ERD diagram
- Table creation script with PK/FK, CHECK constraints and indexes
- Sample data
- 7 reporting queries (monthly sales, top products, top customers, revenue by category, order details, customers without orders, low stock)

## How to run
1. Open `ecommerce_db_sqlserver.sql` in SSMS
2. Execute the script
3. Run the report queries one by one

## Tools
SQL Server (T-SQL), dbdiagram.io
